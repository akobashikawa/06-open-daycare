## Repo at a glance

- Next.js 16.4.0 App Router single-page app (`app/page.tsx`, `app/layout.tsx`), React 19.3.0.
- Turbopack is active: `next dev` and `next build` both run on it. Don't assume webpack semantics.
- Tailwind CSS v4 via `@tailwindcss/turbopack` — CSS is loaded as `*.css` through the turbopack rule in `next.config.ts`, and `app/globals.css` starts with `@import "tailwindcss";`.
- Path alias `@/*` maps to `./*` (tsconfig + Next).

## Conventions & gotchas

- **Generated routes:** `next-env.d.ts` imports `.next/dev/types/routes.d.ts`. Don't hand-write route types; let Next generate them.
- **Cache components / partial prefetching are on** (`cacheComponents`, `partialPrefetching` in `next.config.ts`). Assume `params`/`searchParams` Promises and caching semantics differ from older Next.
- **`experimental.agentFeedback: true`** is set — an OpenCode/agent-feedback experiment. Don't remove it unless you know what it does.
- No tests, no CI workflows, no `.github` in this repo yet. Don't invent a test framework; if tests are added later, wire them into `package.json` scripts explicitly.
- The `references/` folder (HTML screens + PNG screenshots) is a design reference only — it is **not** wired into the app. Don't treat it as live UI or routes.
